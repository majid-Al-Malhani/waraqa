# وَرَقَة — نسخة بلا جافاسكربت

النسخة نفسها من العارض، لكن لا يصل إلى متصفح الزائر سطر جافاسكربت واحد: HTML وCSS فقط.

## أين ذهب العمل؟

لم يختفِ، بل انتقل إلى الخادم:

| المهمة | في النسخة الأولى | هنا |
|---|---|---|
| رسم صفحات PDF | PDF.js في متصفح كل زائر | PyMuPDF مرة واحدة عند الرفع |
| تحميل الصفحات تدريجيًا | `IntersectionObserver` | `loading="lazy"` الأصلية في HTML |
| حجز ارتفاع الصفحة | `aspect-ratio` يضبطها جافاسكربت | وسما `width` و`height` من الخادم |
| الانتقال بين الصفحات | `scrollIntoView` | روابط مرساة `#page-3` |
| مؤشّر موضع القراءة | `IntersectionObserver` + عدّاد | `animation-timeline: scroll()` و`:target` |

## التشغيل

```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

`pages.py` هو الوحدة المسؤولة عن التحويل: دقة 144 نقطة/بوصة، وصيغة WebP بجودة 82، وسقف 200 صفحة للملف الواحد.

## ما الذي كسبته وما الذي خسرته؟

**كسبت:** صفحة تعمل مع تعطيل جافاسكربت ومع القارئات النصية القديمة، وحملًا أخفّ على أجهزة الزوار الضعيفة، وظهورًا أسرع لأول صفحة لأن الصورة جاهزة سلفًا.

**خسرت:**

1. **نص الصفحة لم يعد نصًّا.** الصورة لا تُنسخ ولا تُبحث بـ Ctrl+F ولا تقرأها قارئات الشاشة. هذه أخطر خسارة، وعلاجها الجزئي أن تستخرج نص كل صفحة بـ `page.get_text()` وتضعه في `<figcaption>` مخفي بصريًا.
2. **عدّاد «٣ / ١٢» الحيّ.** لا سبيل في CSS لمعرفة الصفحة المتوسّطة الشاشة؛ استعضتُ عنه بشريط تقدّم يتحرك مع التمرير، وهو خاصية حديثة تدعمها Chrome وEdge ولا تعرضها بقية المتصفحات (والصفحة تعمل كما هي عند غيابها).
3. **مساحة القرص.** ملف PDF من مئة صفحة قد يتحوّل إلى صور بحجم عشرة أضعافه.
4. **زمن الرفع.** التحويل يجري داخل الطلب نفسه، فيتجمّد شريط المتصفح أمام المستخدم إلى أن ينتهي. لهذا وضعتُ `TODO` في `pages.py` لنقله إلى مهمة خلفية.

## الحدّ الأدنى المطلق

إن أردت صفر جافاسكربت وصفر تحويل على الخادم، فسطر واحد يكفي:

```html
<object data="/file/abc__report.pdf" type="application/pdf" width="100%" height="900">
  <p>متصفحك لا يعرض ملفات PDF. <a href="/download/abc__report.pdf">نزّل الملف</a></p>
</object>
```

لكنك هنا تسلّم الملف لعارض المتصفح الداخلي: يعرضه بشكله هو، وبشريط أدواته هو، وبتمريره هو — ولا تملك من التصميم شيئًا.
